# Bouncy Jump Massacre

this game was made from scratch for hackclub haven; no game engine, premade assets or music.

## premise:
bouncy jump massacure is a platformer shooter

## controls:
movement: arrow keys (up to jump, right/left to move)
aiming: wasd (a for counterclockwise, d for clockwise)
shooting: spacebar
