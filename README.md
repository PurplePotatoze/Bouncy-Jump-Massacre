# Bouncy Jump Massacre

this game was made from scratch for hackclub haven; no game engine or premade assets

code (javascript p5.js) : kye tsen

original art: will chia

## premise:
bouncy jump massacure is a platformer shooter where bullets bounce off walls as a fun way to "unalive" enemys.

## controls:
start: any

movement: arrow keys (up to jump, right/left to move)

aiming: <b>e (aims higher)</b> and <b>d (aims lower)</b>

shooting: spacebar

## how it fits the catagory of: "bounce back"
shoot towards the wall in a 90 degree angle and find out!

## fyi
takes a while to load on itch.io, it will be a intro screen for a little while before it starts

## What your score says about you!
To survive this game, you must
- not get touched by enemies
- hit the opposing wall within the time limit
Basically, if you touch the opposing wall, you win <b>2 points</b>
If you kill a enemy, you win <b>1 point.</b>
