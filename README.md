# Bouncy Jump Massacre

this game was made from scratch for hackclub haven; no game engine, premade assets or premade music.

original music: kye tseng

code (javascript p5.js) : kye tseng

original art: will chia

## premise:
bouncy jump massacure is a platformer shooter where bullets bounce off walls as a fun way to "unalive" enemys.

## controls:
start: any

movement: arrow keys (up to jump, right/left to move)

aiming: e and d

shooting: spacebar

## how it fits the catagory of: "bounce back"
play and find out!
